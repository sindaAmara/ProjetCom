Tournoi de Pétanque

Rejoignez-nous pour un moment convivial autour d'une partie de boules

Rubrique : La vie étudiante de l'IUT • Événement annuel

ÉVÉNEMENT PÉTANQUE

📅 Le 27/03 de 13h30 à 18h00

Rejoignez-nous lors de notre tournoi annuel de pétanque qui aura lieu le 27/03 de 13h30 à 18h00.

Le but de ce tournoi est de proposer un moment en toute convivialité afin de se retrouver autour d'une partie de boule.

Choisissez votre partenaire et embarquez dans ce tournoi ensemble !

Pas besoin d'être fort pour y participer. Si jamais vous perdez un match, vous pourriez rejoindre le loser bracket pour avoir une chance de retourner dans le tournoi!

🏆 Prix à gagner :

  • 🥇 1er : Une GameBoy Color
  • 🥈 2ème : Bon de 20€ chez "LE SAMOS"
  • 🥉 3ème : Une sortie au KFC avec Martin Nevot (payée)

Pour les spectateurs comme pour tous les participants, une buvette sera présente afin de vous désaltérer avec vos sodas préférés ou de grignoter grâce aux nombreux snacks disponibles. Tous les fonds récoltés seront versés au BDE.

📍 Rejoignez-nous dans la cour devant le département informatique pour passer un merveilleux moment entre collègues.
